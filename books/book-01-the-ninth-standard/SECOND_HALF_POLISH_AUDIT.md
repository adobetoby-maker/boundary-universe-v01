### Consensus mechanics
Consensus is now audio-legible:
1. Kade asks each participant.
2. Participants actively consent.
3. They retain separate intent/identity.
4. Kade holds a shared boundary model rather than issuing commands.
5. Each participant contributes a previously established specialty.
6. Centralized control is explicitly the failure mode.
7. Participants must be able to choose again when the network is stressed.
8. Physical/neurologic costs remain visible.

This makes Standard IX a category error in-world: the public system labels it as a higher Standard, but Aaron frames it as a different operator architecture.
