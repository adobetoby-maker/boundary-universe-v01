# The Boundary Universe

A living story-development repository for **The Ninth Standard** and connected series.

## Source of truth

The repository is canon. The website is a viewer.

Read in this order before any writing session:
1. `CANON_RULES.md`
2. `handoff/HANDOFF.md`
3. `canon/UNIVERSE_BIBLE.md`
4. `series/ASTERION_TRILOGY.md`
5. `books/book-01-the-ninth-standard/BOOK_BIBLE.md`
6. Current chapter draft and `STATE_LEDGER.md`

## Canon labels

- **LOCKED** — established fact; do not change without an explicit retcon note.
- **PROVISIONAL** — intended direction; may change.
- **SECRET** — true in-world but concealed from characters/readers.
- **RUMOR** — in-world claim that may be false.
- **OPEN** — deliberately undecided.

## Continuity discipline

Every finished chapter must update:
- current character state
- rank/ability progression
- relationship state
- chronology
- revealed secrets
- planted clues
- unresolved questions
- injuries / physical consequences
- promises made to the reader

The goal is a connected-universe saga that can expand without invalidating earlier books.
