Copy this checklist into every new book folder as `PRODUCTION_LOOP.md`.

**Book:** `<title>`
**Series:** `<series>`
**Protagonist:** `<name>`

**Status:** DESIGN

---

## PHASE 0 — DEPENDENCY GATE
- [ ] Series/trilogy bible is coherent.
- [ ] Protagonist opening and trilogy end states are known.
- [ ] Ability rules/costs are documented.
- [ ] Crossover spoiler boundary is documented.
- [ ] Previous-book end-state ledger is reconciled.
- [ ] This book has a one-sentence promise, emotional question, and escalation sentence.

**Gate:** no prose before these are true.

---

## PHASE 1 — BOOK ARCHITECTURE
- [ ] Opening state ledger.
- [ ] Desired end-state ledger.
- [ ] Antagonist/faction pressure map.
- [ ] Relationship arc map.
- [ ] Ability progression map.
- [ ] Mystery/reveal list.
- [ ] Rule 6 clue ledger: 2+ clues per major reveal.
- [ ] School/work/family/ordinary-life rhythm planned.
- [ ] Chapter architecture with expected word count per chapter.
- [ ] Expected total word-count range sanity checked against actual scene count.

### Chapter card schema
For each chapter record:
- number / title;
- expected words;
- opening situation;
- 2–5 real scenes;
- POV;
- character turn;
- relationship turn;
- ability/progression turn;
- clue planted or payoff earned;
- ordinary-life/world job;
- cost/consequence;
- chapter exit;
- dependencies on earlier/later chapters.

---

## PHASE 2 — CHAPTER FOUR-PASS LOOP

Repeat for every chapter before moving to the next chapter.

### PASS 1 — STRUCTURE
- [ ] Full scene spine exists in prose.
- [ ] Chapter fulfills architecture promise.
- [ ] Beginning and exit are strong.
- [ ] No missing causal step.

### PASS 2 — DENSITY
- [ ] Summary converted to scene where the reader needs to experience it.
- [ ] Added words come from scenes, not padded sentences.
- [ ] Ordinary life / relationships / world texture have room.
- [ ] Supporting characters do things for their own reasons.
- [ ] Expected word count is approached naturally.

### PASS 3 — CHARACTER / CLUE / CONTINUITY
- [ ] Protagonist choice is emotionally consistent.
- [ ] Supporting-character agency intact.
- [ ] Progression is earned.
- [ ] Power/ability cost and bookkeeping correct.
- [ ] Clue ledger updated.
- [ ] Every reveal remains fair.
- [ ] Timeline/injury/rank/location/knowledge continuity checked.
- [ ] Connected-universe clue does not punish new readers.

### PASS 4 — AUDIO-FIRST POLISH
- [ ] Speaker attribution clear aloud.
- [ ] Names aurally distinct.
- [ ] Action geography intelligible on one listen.
- [ ] Repeated phrasing reduced.
- [ ] Sentence rhythm varied.
- [ ] Humor does not undercut stakes.
- [ ] Family-clean pass complete.
- [ ] No accidental lore dump.

### CHAPTER ATTESTATION
Record:
- expected production words: `<target>`
- actual words: `<count>`
- pass 1 commit: `<sha>`
- pass 2 commit: `<sha>`
- pass 3 commit: `<sha>`
- pass 4 commit: `<sha>`
- clue/state ledger update commit: `<sha>`
- status: `ATTESTED` / `OPEN`

**Advance rule:** do not start the next chapter until the current chapter is attested, unless an explicit exception ticket records why.

## PHASE 3 — ACT AUDITS

### 25% audit
- [ ] opening promise delivered;
- [ ] reader understands ordinary life;
- [ ] supporting cast differentiated;
- [ ] central problem escalating;
- [ ] no protagonist competence cheat.

### 50% audit
- [ ] midpoint changes the story;
- [ ] relationship arcs have progressed;
- [ ] clue ledger is sufficiently seeded;
- [ ] chapter density distribution checked;
- [ ] world remains lived-in rather than plot-only.

### 75% audit
- [ ] climax prerequisites established;
- [ ] costs visible;
- [ ] supporting arcs converging without becoming protagonist tools;
- [ ] reveals have 2+ prior clues;
- [ ] ending has enough aftermath budget.

## LOOP PRINCIPLES
1. Architecture knows the destination; prose discovers how it feels.
2. Write scenes, not summaries of scenes.
3. Expected word counts diagnose compression; they do not authorize filler.
4. Every major reveal earns two prior clues.
5. Every progression jump earns training, insight, sacrifice, or relationship cost.
6. School/work/family life is story infrastructure, not filler.
7. Supporting characters must remain people when the protagonist leaves the room.
8. Audio quality is part of writing quality, not a downstream conversion problem.
9. Connected-universe links remain optional enrichment until the crossover truly begins.
10. Canon is what was actually published, not what planning documents hoped would happen.
